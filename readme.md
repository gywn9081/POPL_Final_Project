## How To Run

1. install antlr with pip

2. ~ antlr4 -Dlanguage=Python3 Arithmetic.g4

3. ~ python deliverable3.py <text_to_test.txt>

(ex. ~ python deliverable3.py deliverable3.txt or ~ python deliverable3.py project_deliverable_3.py)
